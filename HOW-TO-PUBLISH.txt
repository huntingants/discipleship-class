DISCIPLESHIP CLASS: HOW THE APP IS PUBLISHED
============================================

WHERE IT LIVES
  The app:       https://huntingants.github.io/discipleship-class/
  The code:      https://github.com/huntingants/discipleship-class  (GitHub Pages publishes it automatically)
  The database:  https://supabase.com/dashboard/project/sbfecjnffugvqwzgnnqn

  Keep it at this one address. The Android app, notifications and saved sign-ins are all tied to it.
  Do not publish a second copy elsewhere (Netlify, Cloudflare and so on): students would end up split
  between two apps that drift apart.

CHANGING THE APP
  * Changes go in through git (or through Claude), never by uploading files on the GitHub website.
    An upload on 2026-11-15 replaced the app with an older copy and switched off notifications,
    live updates and several protections until it was restored.
  * Every change runs the app checks automatically (GitHub: Actions tab). A green tick means they passed.
    To run them on a computer: node tests/run-all.js
  * After a change, phones pick up the new version the next time the app is fully closed and reopened.

KEEP THE FREE DATABASE AWAKE (do this once)
  Supabase pauses a free project after about a week with nobody using it. A free website can knock every day.
  1. Go to cron-job.org and make a free account.
  2. Create cronjob. Title: Disciple keep-alive.
  3. URL: https://sbfecjnffugvqwzgnnqn.supabase.co/rest/v1/rpc/ping
  4. Schedule: every day.
  5. Open "Advanced". Under Headers add one header.  Name: apikey   Value: the "key" value inside config.js
     (it is the public key and safe to use here). Without this header the knock is refused (status 401).
  6. Request method: GET. Save, then tap "Test run". A good result shows status 200 and "ok".

DATABASE SETTINGS WORTH TURNING ON (Supabase dashboard)
  * Authentication > Providers/Policies: turn on leaked-password protection.
  * Database > Backups: check that daily backups are on (paid plans) or export now and then.

GOOD TO KNOW
  * New teachers need a one-time invite from the app admin (Class tab > App admin > Invite a teacher).
    Co-leaders join an existing class with its co-leader code.
  * Students see their own journal and nobody else's. Teachers see names, lessons finished, and only the
    journal entries a student chooses to share. Prayer requests marked "Only my teacher" are seen by the
    class leaders only.
  * When the app breaks on someone's phone, a short note appears under Class > App admin > See app problems.
  * The Bible text is the World English Bible (public domain).
